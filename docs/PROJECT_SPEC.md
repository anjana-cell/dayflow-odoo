# Dayflow - HRMS

## Roles
- Employee
- Admin/HR

## Core Features
- Authentication
- Role-based access
- Employee profiles
- Attendance
- Leave management
- Leave approval
- Payroll visibility

## Employee
- View profile
- Edit limited profile fields
- Check-in/check-out
- View attendance
- Apply for leave
- View leave status
- View salary

## Admin/HR
- View employees
- View employee attendance
- Approve/reject leave
- Add comments
- View payroll
- Update salary structure

- Notifications
